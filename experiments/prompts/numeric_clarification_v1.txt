Additional guidance for numeric criteria:
Apply any explicitly stated acceptable range as an inclusive interval. Either endpoint satisfies the numeric target even if it differs from the nominal value. A value outside the interval does not satisfy it merely because it is close. If only an exact acceptable value is specified, do not invent a tolerance. First identify the requested metric, units and scope; unrelated numbers are not answers. Equivalent number formatting preserves a value, but a change in digits can change the value. Apply the same rules regardless of the response language. Preserve the required JSON output format and concise explanation.
